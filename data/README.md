# Data

This folder contains the data used for the evaluation, as well as the scripts used for downloading, sampling, and processing the datasets. It also contains the final quantitative results.

## Directory Structure
* `data_sources/`: Contains scripts used for downloading and reorganizing data.

    * `download_places_coco.py`: Downloads and unzips the sources of the original datasets used.
    * `reorganize_images.py`: Moves images from a batch-based directory structure to a non-batch-based one.
    * `Small-ImageNet-Validation-Dataset-1000-Classes-main/`: Copied from [this repository](https://github.com/ndb796/Small-ImageNet-Validation-Dataset-1000-Classes/): an example of how to load its subset of ImageNet data.
    * `extract_few.sh`: Extracts five samples from each class directory in a standard dataset structure. Necessary for enormous datasets like COCO and Places365.
* `datasets/`: Where the datasets go. Due to potential copyright issues, they are not in this repository: they were uploaded as private Kaggle datasets, which can be downloaded with the `download_kaggle.sh` script after requesting access.
* `eval_csv/`: Contains the CSV files for our quantitative results.

    * `fid_scores_large_nip.csv`: FID scores on samples upscaled with GLIDE's upscaling model that is not fine-tuned for inpainting. The same model was used for all the sampled 64×64 images, which were generated by the listed models.
    * `fid_scores_large.csv`: FID scores on 256×256 images, used in our final report. Each 64×64 sample was upscaled with the upscaling counterpart of the model that generated it.
    * `fid_scores.csv`: FID scores on 64×64 images, for each mask.
    * `lpips_scores_full_nip.csv`: LPIPS scores on samples upscaled with GLIDE's upscaling model that is not fine-tuned for inpainting. The same model was used for all the sampled 64×64 images, which were generated by the listed models.
    * `lpips_scores_full.csv`: LPIPS scores on 256×256 images, used in our final report. Each 64×64 sample was upscaled with the upscaling counterpart of the model that generated it.
    * `lpips_scores.csv`: LPIPS scores on the Places365 validation set only, used in our poster.

* `large_masked_coco/`: Masked versions of images from the COCO dataset, similar to the ones used in our human evaluation survey. Good image source for trying out the model without having to download a full dataset.
* `masks/`: Masks used in our evaluation. Based on the masks provided in the RePaint repository.
